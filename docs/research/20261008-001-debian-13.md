# 20261008-001 – Debian 13 „trixie“ als Zielplattform

## Question
Welche Debian-Version und welche Paketversionen gelten für die Hosts `.222`, `.223`, `.224`, `.225`?

## Why needed
Bootstrap (P01), Ansible-Rollen (P32) und Installationsanleitung brauchen konkrete Versionen.

## Sources
- Debian 13 Release-Ankündigung, 2025-08-09: https://www.debian.org/News/2025/20250809
- Debian Wiki trixie: https://wiki.debian.org/DebianTrixie
- Debian Package Tracker pgvector: https://tracker.debian.org/pkg/pgvector
- Debian Security Tracker CVE-2026-3172: https://security-tracker.debian.org/tracker/CVE-2026-3172
- packages.debian.org podman: https://packages.debian.org/src:podman
- „What to expect from Debian/trixie“ (Michael Prokop, 2025-07-20): https://michael-prokop.at/blog/2025/07/20/what-to-expect-from-debian-trixie-newintrixie/

## Source date/version
Debian 13.0 (2025-08-09), Punktrelease 13.6 (2026-07-11). Abruf 2026-10-08.

## Relevant facts
- trixie liefert Python 3.13, PostgreSQL 17, Nginx 1.26, Podman 5.4.2, Node.js 20.19.
- Debians eigenes `postgresql-17-pgvector` in trixie ist 0.8.0 und laut Security Tracker von CVE-2026-3172 betroffen (Fix 0.8.2, nur forky/sid). Status „no-dsa“.

## Compatibility with our hardware
Alle Hosts sind x86_64; trixie unterstützt die Ryzen-/Xeon-E3-Klasse ohne Einschränkung.

## Compatibility with our versions
- Python 3.13 erfüllt „Python 3.12+“.
- Vite 8 benötigt Node.js ≥ 20.19 oder ≥ 22.12 → trixie-Node 20.19 genügt knapp; wir installieren Node 22 LTS aus NodeSource auf `.223` (Build) bzw. bauen das UI auf `.225`/CI und kopieren nur `dist/`.

## Rejected alternatives
Debian 12 bookworm (Python 3.11, Podman 4.3) – erfüllt „Python 3.12+“ nicht ohne Fremdquellen.

## Decision fixed by architecture
Debian ist Zielsystem; Stack bleibt Python/PostgreSQL/Podman/Nginx.

## Implementation consequences
- PostgreSQL 17 + pgvector aus dem PGDG-Repository (apt.postgresql.org, Suite `trixie-pgdg`), nicht aus Debian, damit pgvector ≥ 0.8.2 verwendet wird (siehe 003).
- Ansible-Rolle `common` setzt trixie voraus und prüft `/etc/debian_version`.
- Build-Umgebung dieses Repos ist Ubuntu 24.04 (Python 3.12, PostgreSQL 16, pgvector 0.6.0) – nur für Tests; Produktionsversionen siehe Installationsanleitung.

## Open risks
Fremdquellen (PGDG, NodeSource, NVIDIA 580) müssen gepflegt werden.
