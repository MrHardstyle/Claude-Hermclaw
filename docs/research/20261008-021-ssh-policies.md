# 20261008-021 – SSH-Policies (Admin-Tools, Worker-Zugang)

## Sources
- SSH.com: Authorized Keys für OpenSSH: https://www.ssh.com/ssh/authorized_keys/openssh
- Simplified Guide: Befehle pro Key einschränken: https://www.simplified.guide/ssh/restrict-authorized-keys-command
- sshd(8) / sshd_config(5): https://man.openbsd.org/sshd_config

## Relevant facts
- `authorized_keys`-Optionen: `restrict` (keine PTY/Forwarding), `command="…"` (erzwungenes Kommando, Original in `SSH_ORIGINAL_COMMAND`), `from="CIDR"`.
- `sshd_config` `Match User … ForceCommand …`.

## Implementation consequences
- Dedizierter Benutzer `hermclaw-admin` auf Zielhosts; Key mit `restrict,from="192.168.178.225"` und optional `command="/usr/local/bin/hermclaw-ssh-gate"`; das Gate prüft `SSH_ORIGINAL_COMMAND` gegen eine Allowlist.
- Runtime: Host-Allowlist, Kommando-Klassifikation (read/mutate/destructive/forbidden), sudo nur per Allowlist, Timeout, Audit-Events.
- `ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o UserKnownHostsFile=/etc/hermclaw/known_hosts`.
