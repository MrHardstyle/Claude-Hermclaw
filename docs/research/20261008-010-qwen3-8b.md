# 20261008-010 – Qwen3 8B (Fast Router)

## Question
Wie wird Qwen3 8B als Fast Router (16K) betrieben?

## Sources
- Qwen3 README (GitHub-Spiegel): https://github.com/coderonion/Qwen3
- LM Studio Modellseite: https://lmstudio.ai/models/qwen/qwen3-8b
- ollama-python Issue think-Parameter: https://github.com/ollama/ollama-python/issues/576
- Ollama Thinking: https://docs.ollama.com/capabilities/thinking.md

## Relevant facts
- Tag `qwen3:8b`; hybrides Thinking (Standard an), Umschalten über `think` bzw. `/no_think`.
- Kein Greedy-Decoding im Thinking-Modus empfohlen; für Klassifikation genügt Non-Thinking, Temperatur niedrig.
- Ollama-Default-Kontext zu klein → `num_ctx=16384` explizit.

## Compatibility with our hardware
~5–6 GB Q4 → vollständig in 8 GB VRAM möglich.

## Decision fixed by architecture
Fast Router = `qwen3:8b`, 16K, Alias `fast-router`.

## Implementation consequences
- Aufrufe mit `think:false` und JSON-Schema (Intent/Triage); Ergebnis validiert, Fallback auf deterministische Heuristik bei ungültiger Antwort.

## Open risks
`think:false` wurde in älteren Versionen ignoriert → Ausgabe wird nur aus `content` gelesen.
