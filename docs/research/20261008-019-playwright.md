## Relevant facts
- `page.route` ersetzt XHR/fetch-Antworten; ein gemockter SSE-Body ist eine abgeschlossene Antwort → für Live-/Reconnect-Tests einen echten lokalen Stream-Server nutzen.
- Aktuelle Version 1.60/1.61.

## Implementation consequences
- UI-E2E läuft gegen das echte Backend im Testmodus (lokales PostgreSQL, Fake-Modelle) → echte SSE-Streams.
- Chromium der Build-Umgebung unter `/opt/pw-browsers`.
