# 20261008-014 – Nginx als UI-Server und SSE-Proxy (`.223`)

## Sources
- SSE durch Nginx (oneuptime, 2025-12-16): https://oneuptime.com/blog/post/2025-12-16-server-sent-events-nginx/view
- STIG Manager Reverse-Proxy-Doku (X-Accel-Buffering): https://stig-manager.readthedocs.io/en/1.5.13/installation-and-setup/reverse-proxy.html
- nginx proxy-Modul: https://nginx.org/en/docs/http/ngx_http_proxy_module.html
- Debian 13: Nginx 1.26: https://www.debian.org/News/2025/20250809

## Relevant facts
- Für SSE: `proxy_http_version 1.1`, `proxy_set_header Connection ""`, `proxy_buffering off`, `proxy_cache off`, `gzip off`, langer `proxy_read_timeout`.
- Upstream-Header `X-Accel-Buffering: no` wird von Nginx ausgewertet.
- Heartbeats verhindern Idle-Timeouts.

## Decision fixed by architecture
Nginx auf `.223`, statisches React-Build unter `/var/www/hermclaw-next`, Proxy zur API auf `.225:8000`.

## Implementation consequences
- `infra/nginx/hermclaw-next.conf`: `location /api/` (normal) und `location ~ ^/api/jobs/[^/]+/events/stream$` (SSE-Spezialblock).
- API sendet `X-Accel-Buffering: no` und alle 15 s einen SSE-Kommentar.
- `nginx -t` als Deploy-Gate.
